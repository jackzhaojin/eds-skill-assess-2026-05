# 2026-05 EDS Skill Assessment with MLflow

Evaluation of Adobe's `create-site` skill (v1.1.0) from
https://github.com/adobe/skills/tree/main/plugins/aem/edge-delivery-services/skills/create-site

## Layout

```
.
├── README.md                    # this file
├── rubric.md                    # pre-run input — context, weights, must-haves
├── skill-under-test/            # Adobe create-site v1.1.0 (the artifact being graded)
│   ├── SKILL.md
│   ├── CHANGELOG.md

│       └── ...19 sibling skills
├── scorers/                     # rule-based scorers Claude Code will write here

    └── 2026-05-create-site.md   # generated by the eval run
```

## One-time setup (your Mac)

```bash
# MLflow 3.x for genai/judges API
pip install 'mlflow>=3.4'

# Official MLflow skills package — agent-evaluation, tracing, trace-analysis
git clone https://github.com/mlflow/skills.git ~/.claude/skills/mlflow

# OpenAI API key for the judges (gpt-5.4-mini at $0.75/$4.50 per 1M tokens,
# ~$0.20-0.40 per eval pass)
# Claude Code itself runs via your Max OAuth — no Anthropic API key needed
export OPENAI_API_KEY=sk-...
```

## Per-run sequence

```bash
# 1. Local MLflow tracking server (leave running in a tab)
mlflow server --host 127.0.0.1 --port 5000

# 2. Start tracing this workspace
cd ~/path/to/2026-05-eds-skill-assessment-with-mlflow
mlflow autolog claude . \
  --tracking-uri http://127.0.0.1:5000 \
  --experiment-name "eds-skill-assessment-2026-05"

# 3. Open Claude Code in this directory and run the prompt below.
```

## Eval prompt

Paste this into Claude Code from the workspace root:

```
Evaluate the skill at ./skill-under-test/ against the criteria in ./rubric.md.

Use the MLflow agent-evaluation skill to scaffold this:
- Load the instrumenting-with-mlflow-tracing skill first
- Configure all judges with model="openai:/gpt-5.4-mini" (cost-controlled, strong on agentic tasks)

Apply LLM judges for each scoring dimension listed in rubric.md.
Generate the rule-based scorers in ./scorers/ — at minimum:
  - frontmatter_validity (name, description, license, version)
  - description_length (≤1024 chars per Anthropic guidance)
  - referenced_files_exist (any relative paths in SKILL.md resolve)
  - must_have_patterns (from rubric.md "Must-have" section)
  - must_not_have_patterns (from rubric.md "Must-not-have" section)
  - link_health (HEAD-check the 8 reference URLs in SKILL.md References section)

Compare voice, structure, and cross-referencing patterns against 2–3 sibling
skills under ./adobe-skills-repo/plugins/aem/edge-delivery-services/skills/
(suggest: page-import, content-driven-development, building-blocks).

Pause for my input at each judgment where the rubric's "Pre-run Notes from the
Human Judge" section flags an open question.

Log all judge scores, rationales, and rule-check results as a single MLflow
experiment run. Produce the final scorecard at ./scorecards/2026-05-create-site.md
in the format specified at the bottom of rubric.md.
```

## After the run

1. Open MLflow UI: http://127.0.0.1:5000
2. Find the experiment `eds-skill-assessment-2026-05`
3. For each judge: review rationale, override score if needed, attach feedback note
4. Once you have ≥10 graded skills across vendors, run judge alignment to calibrate
   future runs to your standards (see MLflow docs: `judge.align(traces)`)

## Notes for future evaluations

- Keep one workspace per evaluation period (`2026-05-...`, `2026-06-...`) for clean traces
- The `adobe-skills-repo/` clone uses sparse-checkout — only the EDS plugin is pulled
- The `rubric.md` is the contract; everything else flows from it. Edit the rubric first if you're shifting weights or adding criteria.
